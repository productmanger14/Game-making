# ARENA — 검투 구단 매니저 0.6.1

Windows용 오프라인 싱글플레이 게임입니다. `ARENA-Manager-0.6.1-Windows.exe`를 실행하세요. 실행할 때마다 **구단 생성 화면**부터 시작합니다. 기존 자동 저장이 있으면 같은 화면의 **이어하기**로 재개할 수 있습니다.

## 0.6.1 시작 화면 수정

- 자동 저장 때문에 구단 생성 화면을 건너뛰던 흐름을 수정했습니다. 국가·도시·구단 이름·감독 정보를 바로 입력할 수 있습니다.
- 저장된 구단·감독·진행 날짜를 표시하며, 경기 도중 저장했다면 해당 세트 준비부터 이어갑니다.
- 시작 화면을 여는 것만으로 기존 자동 저장을 덮어쓰지 않습니다. 새 구단 창단 시 저장 교체를 확인하며, 취소하면 기존 경력과 입력 내용이 유지됩니다.
- 시작 화면에서 저장 파일 불러오기·내보내기를 지원합니다. 읽지 못하는 저장도 원본을 내보낸 뒤 새로 시작할 수 있습니다.
- 기존 버전이 실행 중이면 창을 완전히 종료한 뒤 새 실행 파일을 여세요. 게임은 중복 실행 시 이미 열린 창을 표시합니다.

## 0.6.0 기술과 플레이스타일

- 선수당 **습득 스킬 최대 7개**, 스킬 숙련은 **Lv.1~10**입니다. 기존 1~20 능력치는 그대로 유지합니다.
- 일반 스킬 23종: 검술·방패술·곡도술·창술·궁술·석궁술·중병기술·채찍술·연검술·봉술·사슬낫술, 보법·격투술·호흡법·무기 유지술·무장 해제술, 진형 유지·측면 공략·호위술·간격 조절·압박술·깃발 운반술·험지 적응.
- 역사·신화 모티브 100명은 각자 기본 기술 하나를 Lv.3으로 보유합니다. 이 기술도 7칸에 포함되며 다른 선수에게 가르치거나 정리할 수 없습니다. 기존 고유 특성 보너스는 이 기술로 대체하며 중복 적용하지 않습니다. 유니크 배지나 도감은 없습니다.
- 내 선수 상세의 **기술·플레이스타일**에서 습득 기술, 효과, 발동 조건, 레벨과 경험을 확인합니다. 다른 구단 선수의 기술도 읽기 전용으로 조회합니다.
- **훈련센터 → 개인 훈련 → 전담 기술 훈련**에서 새 기술을 배우거나 보유 기술의 숙련을 올립니다. 선수 상세에서도 설정할 수 있습니다. 새 기술은 입문 경험 100에서 Lv.1로 습득합니다.
- 훈련 시설·코치·강도·훈련 의욕·피로가 기술 훈련에 반영됩니다. 회복·휴식 전용 날, 경기일과 부상 중에는 전담 훈련을 하지 않습니다. 배운 기술은 출전 세트당 경험 3을 얻으며 장비가 다른 무기 전용 기술은 제외합니다. 습득·레벨 상승은 새 소식과 훈련센터에 기록합니다.
- 7칸이 찼다면 일반 기술을 **정리**하고 다른 기술을 배울 수 있습니다. 확인 후 해당 기술의 레벨과 경험이 사라집니다. 기본 기술은 정리할 수 없으며 경기 준비·진행 중에는 기술을 변경할 수 없습니다.
- 기술은 실제 전투의 명중·방어·피해·이동·체력·공격 간격·무장 해제에 반영됩니다. 간격 유지·협공·호위·압박·대열 유지·운반 선호에 따라 이동과 표적 선택도 달라집니다. 수치 효과는 레벨에 비례하고 중복 효과에는 상한이 있습니다.
- 지휘관의 전술은 소규모 냉병기 교전으로, 신화의 초자연적 기량은 신체·기술·전술로 재해석합니다. 기본 기술 중 유사한 전술은 공통 효과 유형을 사용합니다. 마법·불사·총기 효과는 없습니다.
- 기존 저장에 없는 스킬은 선수별로 고정 배정합니다. 이적·시즌 전환·재실행 후에도 습득과 레벨이 유지됩니다. 해외 간이 경기는 기술을 전력 보정으로 반영하며, 정밀 위치와 시간별 효과를 모두 재현하는 방식은 아닙니다.

성장식·발동 조건·전투 보정 상한·모티브 해석과 출처는 [기술 설계 문서](docs/skill-design.md)에 정리했습니다. 기술 가격을 몸값에 따로 더하지 않으며, 당해 경기 실적을 통해 간접 반영합니다.

## 0.5.1 시즌 실적과 명성 기반 몸값

몸값은 **이번 시즌 기록**으로 계산합니다. 통산 기록은 별도로 보존하며 가격 산식에는 사용하지 않습니다. 선수단·세계 탐색·리그 선수 기록도 이번 시즌을 기본으로 표시하고, 선수 상세에서 시즌/통산 기록과 명성을 함께 확인합니다. 다른 구단과 자유계약 선수의 상세 가격은 스카우트 신뢰도에 맞는 범위로 표시합니다.

기본 단위는 백만원입니다.

```text
시즌 실적 = (킬×3 + 어시스트×1.5 + 깃발 운반×0.5 + 에이스 승리×8 − 데스)
            ÷ max(5, 이번 시즌 출전 세트 수)
기준가 = max(6, 12 + 시즌 실적×5 + 명성×0.8 + 25세 미만 보정 8)
몸값 = 기준가 × 기존 모티브 보정(해당 시 1.2), 백만원 단위 반올림
```

명성은 0~100이며 기존 1점당 0.4에서 **0.8백만원**으로 반영 비중을 높였습니다. 5세트 미만은 분모를 5로 두어 소수 경기의 급등락을 줄입니다. 새 시즌에는 해당 시즌 기록을 0으로 초기화하므로 실적 가산분도 새로 평가하며, 통산 기록과 명성은 유지합니다. 별도의 전 시즌 실적 이월이나 가격 평활화는 없습니다. 새 선수는 실적 0에서 시작하고 명성·나이를 반영합니다.

내 경기, 같은 리그의 다른 경기, 해외 간이 경기 모두 시즌/통산 기록을 함께 갱신합니다. 명성도 동일하게 킬을 올린 출전 세트당 1 증가(최대 100)하며 외국 선수의 명성은 저장 후 재실행과 시즌 전환에도 유지합니다. 이적해도 그해 기록이 끊기지 않습니다. 자유계약 계약금은 새 몸값의 35%를 백만원 단위 올림하며 새 구단 영입 제안에도 새 기준을 사용합니다. 이미 받은 제안의 금액은 제안 당시 금액입니다.

기존 첫 시즌(2026) 저장은 통산 기록이 그 시즌 기록이므로 복원합니다. 그 이후 시즌의 구 저장은 연도별 기록이 없으므로 통산과 명성을 보존하고 업데이트 이후 실적만 집계하며, 상세/리그 화면과 새 소식에서 안내합니다. 외국 선수는 세계 리그 생성 시즌의 기록임이 확인되는 경우 복원합니다. 이후 새 시즌부터는 온전한 시즌 기록을 사용합니다. 세트 사이 저장은 경기 종료 시 전체 세트 기록을 한 번만 정산합니다.

경기 종목별 실적 보정, 포지션별 기여도, 계약 잔여 기간, 부상·리그 수준, 구단마다 다른 이적 제안 가격은 아직 몸값 산식에 포함하지 않습니다. 유니크 표시나 도감은 추가하지 않습니다.

## 0.5.0 재정센터

사이드바의 **재정센터**에서 **재정 현황 / 중계권·후원 / 거래 장부**를 전환합니다. 화면과 아래 금액의 기본 단위는 백만원입니다. 0.01백만원은 1만원이며, 거래마다 이 단위로 정산합니다.

| 항목 | 적용 규칙 |
| --- | --- |
| TV 공동 중계권 | 첫 시즌 28 × 14회 = 392. 경기일에 자동 분할 지급. 다음 시즌은 전 시즌 1~2위 32/회, 3~4위 30/회, 그 외 28/회 |
| 편성 중계료 | 계약 화면에 공개된 약 4~5개 편성 경기 정상 종료 시 8 추가 지급 |
| 고정형 후원 | 계약금 최대 20 + 매주 12 |
| 성과형 후원 | 계약금 최대 10 + 매주 7 + 승리당 10 |
| 입장 수입 | 홈 경기 관중 × 입장권 가격. 수용 인원 4,500명, 가격 10,000~40,000원. 명성·승률·가격에 따라 관중 수 변동 |
| 홈 경기 운영비 | 8 + 관중당 2,000원 |
| 경기 수당 | 승리 30 / 패배 15. 이전 버전의 일괄 수입 110/55는 새 구조로 교체 |
| 시즌 상금 | 1~8위 순서로 240 / 180 / 140 / 110 / 90 / 70 / 50 / 30. 마지막 경기 후 한 번 지급 |
| 주간 운영비 | 1군 주급 합계 + 유스 주급 합계의 25% + 스태프 팀 레벨 합계 × 2 + 시설 레벨 합계 × 3 |
| 기권 | 경기 수당·입장 수입·편성 중계료·승리 후원금 없음. 벌금 20 지출 |

후원사는 시즌당 한 곳을 선택합니다. 계약금은 남은 경기 비율로 계산하며, 주간 후원금은 계약 다음 정산일부터 지급합니다. 다음 시즌에는 새 후원사를 선택할 수 있습니다. TV 분배금은 리그 공동 계약이므로 별도 협상 없이 지급됩니다.

모든 영입·매각·계약 해지·시설 투자·스태프 보강·스카우팅·유스 모집·자동 정산이 같은 장부에 기록됩니다. 월별 수입·지출·순현금흐름, 항목별 그래프, 월초·마감 잔액, 날짜·항목·입출금 필터와 거래별 잔액을 제공합니다. 지난 시즌 결산과 상세 거래도 보존합니다.

향후 최대 28일 자금 전망은 현재 선수단과 가격을 유지하고 남은 경기를 정상 진행한다고 가정합니다. TV·후원 계약 수입, 입장·편성 중계료·패배 기준 경기 수당, 급료·시설·홈 운영비를 반영하며 승리 보너스·순위 상금·신규 영입·투자는 제외합니다. 시즌 종료 이후의 가상 수입이나 비용은 계산하지 않습니다.

기존 저장의 잔액은 그대로 유지하고 업데이트 날짜부터 장부를 작성합니다. 과거 거래를 임의 재구성하거나 지난 TV 분배금을 소급 지급하지 않습니다. 재실행·저장 복원으로 지급금이 중복되지 않도록 거래별 정산 키를 저장합니다. 자동 운영비로 잔액이 음수가 되면 재정 보고가 도착하고 선택 지출은 제한되지만, 대출·파산·이사회 지원은 아직 없습니다. 다른 구단의 독립적인 재정 시뮬레이션, 상품 판매, 급료 협상과 회계상 감가상각도 현재 범위에 포함하지 않습니다.

재정 검증은 14회 중계료·홈/원정 정산·시즌 상금·후원 선택과 재계약·주간 비용·음수 잔액·이관·월말·장부 잔액 일치를 포함합니다. Chromium에서 가격 변경, 후원 체결, 시설 지출, 장부 필터와 저장 복원을 확인했습니다. 승강제가 실제로 작동하는 것처럼 보였던 기존 안내 문구도 실제 구현 범위에 맞게 수정했습니다.

## 0.4.0 세계 탐색

사이드바의 **세계 탐색**에서 국가 → 리그 → 구단 → 선수 상세로 이동합니다. 기존 **리그 현황**의 구단 이름도 선수단 화면으로 연결됩니다.

- 12개국, 국가별 8팀으로 구성한 96개 구단의 리그 순위와 라운드별 전체 일정을 조회합니다.
- 구단별 로스터, 이름 검색·포지션 필터·능력/킬/나이 정렬, 최근 결과와 다음 상대를 확인합니다.
- 선수 이름을 누르면 고정된 초상, 능력 평가, 시즌·통산 경기 기록과 코치·스카우트 관찰 보고서를 볼 수 있습니다. 외부 선수의 능력은 관찰 신뢰도에 따라 범위로 표시하며, 내 구단 전용 대화·방출 버튼은 제공하지 않습니다.
- 리그 선수 기록 탭에서 이번 시즌 킬·어시스트·깃발 운반·에이스 승리 상위 50명을 조회합니다.
- 다른 국가의 경기는 날짜 진행 시 자동 집계됩니다. 소속 리그의 다른 구단 경기는 감독의 경기가 끝날 때 집계됩니다. 전력·꾸준함·중요 경기 성향을 반영한 5판 3선승 간이 시뮬레이션이며, 3D 관전 경기를 직접 돌리는 방식은 아닙니다.
- 소속 리그의 로스터는 실제 저장된 선수단을 참조하므로 이적이 즉시 반영됩니다. 다른 국가 선수는 구단별 고정 생성값과 누적 기록으로 저장해 재실행해도 이름·외모·능력이 바뀌지 않습니다.
- 기존 저장을 자동 변환합니다. 이미 진행한 소속 리그 경기는 보관된 내 경기 결과만 복원하고, 남아 있지 않은 다른 구단의 과거 점수는 **기록 없음**으로 표시합니다. 이전 버전에 없던 타 국가 리그는 현재 날짜까지 집계해 생성합니다.

현재 탐색은 국가별 한 개의 8팀 리그를 대상으로 합니다. 외국 구단으로 이적 제안하기, 여러 디비전과 대륙·월드리그는 아직 지원하지 않습니다. 0.5.1부터 선수 기록은 **이번 시즌**을 기본으로 표시하며 통산 기록은 선수 상세에 보존합니다.

## 이번 버전의 플레이 흐름

구단 생성 → 일정·훈련·영입 관리 → 하루/다음 경기까지 진행 → 응답이 필요한 새 소식 처리 → 경기일 전술·정확한 인원 선발 → 세트 진행 → 다음 세트 전술·명단 재설정 → 경기 종료와 회복.

- **구단 생성**: 12개 나라, 나라별 8개 연고 도시, 구단 이름·감독 이름·나이·구단 색상. 나라에 맞는 상대 구단과 선수 이름, 도시 특성을 반영한 홈 경기장.
- **일정**: 월별 캘린더, 14경기 시즌 일정, 홈·원정·경기장·결과. 다음 경기까지 진행은 경기일이나 필수 응답 이벤트에서 멈춥니다.
- **훈련센터**: 반복 주간 오전·오후 세션, 강도, 경기 전후 자동 관리, 개인 훈련과 역할 적응, 성장·피로·의료 보고. 시설과 코칭 팀 수준이 성장에 반영됩니다.
- **새 소식**: 경기·훈련·이적·구단·이벤트 분류, 미확인 표시, 상세 보고, 응답 선택. 후원 제안, 지역 테스트, 선수 매각 제안, 경쟁 구단 영입, 유스 승격과 개인 면담을 지원합니다.
- **전술과 명단**: 종목별 선수·대형·운영·공격 우선 대상·세트 역할을 저장합니다. 세트마다 정확한 인원을 제출하고 왕과 에이스를 직접 선택합니다. 피로는 이어지며 선수를 교체할 수 있습니다.
- **전투**: 11:11 섬멸전, 20:20 깃발 운반전, 9:9 데스매치(30초 리스폰), 5:5 왕잡기, 1:1 에이스전. 최대 인게임 60분, 5판 3선승제. 깃발은 각 진영에 3개, 아군 기지로 운반해 득점합니다.
- **선수 초상**: 역사·신화 모티브 100명에 서로 다른 고정 애니풍 초상을 배정했습니다. 도감·별·유니크 표시는 없습니다. 일반 선수는 별도의 기존 초상 풀에서 배정됩니다. 일반 선수마다 새로운 이미지를 온라인 생성하는 기능은 없습니다.
- **능력치**: 22개 개별 능력치와 무기 숙련, 16개 숨겨진 능력치를 1~20으로 관리합니다. 역할 OVR·잠재력 평가는 기존 100점 표시, 내부 성장 용량은 별도입니다.

## 숨겨진 성향

꾸준함, 거친 플레이, 중요 경기 활약, 다재다능, 부상 빈도, 프로 의식, 야망, 충성심, 압박 대처, 침착한 성품, 스포츠맨십, 적응력, 논쟁성, 집착도, 질투 성향, 경계 존중을 포함합니다.

제공된 FM 설명을 참고해 이 게임에 맞게 설계한 확률 모델입니다. 꾸준함은 경기 단위로 기량 발휘를 판정하며, 중요 경기 활약과 압박 대처는 시즌 막판 경기에 영향을 줍니다. 역할 친숙도와 다재다능은 다른 역할의 효율·학습에, 프로 의식과 야망은 성장에, 부상 빈도·피로·지구력·의료 시설은 훈련 중 회복 필요성에 반영됩니다. 거친 행동은 심판 주의로 이어지고, 한 세트에서 3회 주의를 받으면 해당 세트에서 실격합니다. 꾸준한 출전과 중요 경기 경험으로 일부 숨겨진 능력이 소폭 성장합니다.

숨겨진 숫자는 선수 화면에 공개하지 않습니다. 코치·스카우트 관찰은 평가 신뢰도에 따라 정성적인 문구로 표시합니다. 집착·질투는 성인 1군 선수의 개인 면담 이벤트에 반영되며, 감독은 관계를 안심시키거나 개인적 경계를 설명할 수 있습니다. 연애 관계가 출전권을 자동 결정하거나 직접적인 전투 보너스를 주지는 않습니다.

## 저장

자동 저장 위치는 운영체제 앱 데이터 폴더의 `ARENA-Manager`입니다. 실행 파일을 교체해도 같은 저장을 사용합니다. 이전 저장 형식은 선수·예산·기록을 보존해 변환합니다. 기존 저장은 최초 변환 때 별도 브라우저 저장 키에도 백업됩니다. 파일 내보내기/불러오기로 다른 컴퓨터로 옮길 수 있습니다.

세트 시작 전과 종료 후에 진행을 저장합니다. 진행 중 종료하면 **현재 세트 준비 단계**부터 다시 시작하며, 앞서 완료한 세트의 결과와 피로는 보존됩니다.

## 개발·빌드

Node.js 22 이상에서 `npm ci`, `npm start`로 실행합니다.

- `npm test`: 경기 엔진, 깃발·리스폰 규칙, 경력 운영, 숨겨진 능력과 고정 초상 ID, 세계 리그 동기화, 재정 정산, 시즌 몸값·이적 기록 유지·구 저장 이관, 기술 7칸·10레벨·고유 기술·훈련·실전 효과·해외 성장 저장 검증.
- `npm run build:win`: `release/v0.6.0/`에 Windows x64 휴대용 실행 파일 생성.
- `npm run build:linux`: 같은 버전 폴더에 Linux AppImage 생성.

빌드는 버전별 출력 폴더를 비운 뒤 진행해 이전 패키지가 섞이지 않도록 합니다. Windows 실행 엔진과 DLL의 PE 구간을 패키징 전후에 검사하며, 파일이 잘렸으면 빌드를 실패 처리합니다. 배포 파일은 서명되지 않았습니다. Three.js·초상·한글 글꼴을 모두 포함하며 게임 실행에 인터넷 연결은 필요 없습니다. Noto Sans KR의 SIL OFL 라이선스와 Three.js 라이선스는 `dist/assets/`에 포함되어 있습니다.

## 검증과 현재 범위

60회 종목 시뮬레이션, 12개 시즌과 등장 스케줄, 경기일 진행 제한, 필수 응답, 훈련 부하·성장, 세트별 인원 검증, 이적 완료·최소 로스터, 저장 이관·복원, 100개 고정 초상 ID, 숨겨진 능력 범위와 효과를 검증합니다. 실제 Chromium 화면에서 구단 생성, 전체 메뉴, 훈련 수정, 이벤트 응답, WebGL 경기, 세트 사이 새로고침, 한 경기 완료·회복일, 초상과 관찰 보고서를 확인했습니다. Windows 자체의 실행 검증은 사용자 환경에서 필요합니다.

직접 감독하는 대회는 소속 국가의 8팀 리그이며, 11개 다른 국가의 리그를 탐색할 수 있습니다. 여러 디비전의 완전한 승강, 대륙·월드리그, 복잡한 이적 협상, 개인 스태프 경력은 아직 확장 대상입니다. 다른 구단끼리 치르는 경기는 전력 기반 간이 시뮬레이션으로 결과와 선수 기록을 함께 집계합니다. 3D 모델과 경기장 이동은 기본적인 전술 관전용 표현입니다.

탐색 기능은 96개 구단·2,880명 고유 ID, 타 국가 616경기, 승패·점수·킬/데스 합계, 재실행 중복 집계 방지, 이적 반영, 시즌 전환, 저장 용량을 검증했습니다. Chromium 화면에서 국가 이동, 선수 검색·필터, 외부 선수 읽기 전용 상세, 라운드 선택, 선수 기록, 저장 복원과 최소 데스크톱 창 크기도 확인했습니다.
