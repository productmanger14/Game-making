# 기술 시스템 0.6.0

선수당 습득 기술 7개(기본 기술 포함), 기술당 Lv.1~10. UI에는 희귀도·유니크 배지와 도감을 제공하지 않는다. 아래 모티브 표는 개발 참고 자료이며 게임 메뉴가 아니다.

## 능력치와 기술의 역할

기존 1~20 능력치와 무기 숙련은 기초 기량이다. 기술은 사용 무기, 아군 배치, 경기 유형, 지형, 체력, 교전 상황에 따라 달라지는 보정과 행동 성향이다. 별도 주문·마법·플레이어 액티브 버튼은 없다. 기존 고유 특성의 상수 보정은 제거하고 기본 기술 1칸으로 대체한다.

일반 선수는 주 무기 기술, 역할 기술, 신체·운용 기술 등 3~4개를 Lv.2~4로 시작한다. 유스는 Lv.1. 모티브 선수는 자기 기본 기술을 Lv.3으로 추가하며 7칸에 포함한다. 신생 모티브 선수의 장비는 무기 의존 기술에 맞춰 배정한다. 기존 선수의 장비와 능력치는 보존하므로 일부 무기 기술은 장비 조건을 충족하지 않으면 발동하지 않는다. 이 경우 화면에 표시한다.

## 성장과 변경

훈련센터 및 내 선수 상세에서 한 가지 전담 기술을 선택한다. 새 기술은 입문 경험 100에서 Lv.1이 되며, 보유 기술의 다음 레벨 경험은 80 + 현재 레벨 × 40이다. Lv.10에서는 경험 0으로 고정하고 훈련 목표를 해제한다. 입문 중 다른 기술로 변경하면 입문 경험만 사라진다. 이미 습득한 기술의 레벨과 경험은 목표 변경으로 지워지지 않는다.

하루 전담 경험 = (6 + 훈련시설 레벨×2 + 코치 레벨) × 강도 × 훈련 의욕 × 활동 세션 수/2. 시작 피로가 65를 넘으면 절반이다. 경기일·회복/휴식 전용 날·부상 중은 전담 경험을 얻지 않는다. 매 출전 세트에서 배운 기술에 경험 3을 더하며, 장비가 다른 무기 전용 기술은 제외한다. 실제 경기에서는 경기 종료 시 기록과 함께 한 번만 정산한다. 출전 경험은 조건부 효과의 실제 발동 횟수와 별도다.

7개를 채웠다면 일반 기술을 정리해 빈칸을 만든다. 정리는 확인 후 해당 레벨과 경험을 지우며, 기본 기술은 정리·양도·타 선수 학습이 불가능하다. 경기 준비와 진행 중 변경을 차단한다. 기술과 숙련은 이적·시즌 전환 시 유지된다.

## 행동과 전투 반영

유효타·방어·회피·방어 관통·무장 해제·유지는 확률 %p, 피해·이동·체력 절약·공격 간격·회수 대기는 비율이다. 표의 효과는 Lv.10이며 실제 효과는 레벨/10에 비례한다. 동일 효과 합계 상한은 유효타 20%p, 방어 22%p, 회피 16%p, 피해 35%, 이동 30%, 체력 절약 40%, 공격 간격 28%, 관통 14%p, 무장 해제/유지 각각 4%p, 회수 대기 55%다.

가장 높은 레벨의 행동 기술을 기본 성향으로 사용한다. 같은 레벨이면 기본 기술과 기존 습득 순서가 우선이다. 협공은 동료가 노리는 적을, 호위는 왕·운반자 가까이의 적을 우선한다. 호위는 왕·운반자를 따라가며 간격 유지는 사거리 안에서 물러나고, 압박은 더 가까이 접근한다. 대열 유지는 멀리 떨어진 아군에 재합류하며 운반 우선은 깃발 운반 역할을 택한다. 감독의 목표 지시와 경기 임무도 적용한다.

해외·국내 다른 구단의 간이 경기는 스킬을 전력 보정으로 반영하고 출전 경험을 저장한다. 정밀 위치와 시간에 따른 효과를 모두 재현하는 것은 아니며 일부 조건부 기술은 간이 경기 전력 보정에서 제외된다. 개인 능력 OVR과 몸값에 별도 스킬 가격을 붙이지 않고, 실제 결과와 시즌 실적을 통해 간접 반영한다.

## 역사·서사 모티브 적용 원칙

역사 인물은 지휘·전술·무예의 기록에서 착안한다. 지휘관의 전술을 개인이 실제로 사용한 필살기라고 주장하지 않는다. 신화와 문학 인물은 해당 전승을 모티브로 삼으며 역사적 사실로 분류하지 않는다. 기술 이름(이천일류 등 실제 명칭 제외), 발동 조건, 수치는 게임용 창작이다. 함대·기병·화포 작전은 도보 냉병기 경기의 협공·기동·방어로 재해석한다. 불사·주문·분신·번개·비행은 사용하지 않는다.

관우의 청룡언월도, 조운의 일당백 수치, 신겐과 겐신의 개인 결투 등 대중적 창작을 정사로 단정하지 않는다. 람세스의 카데시 묘사는 왕실의 자기 서술임을 구분한다. 기본 기술은 100개 개별 ID를 가지며 유사한 전술 모티브는 공통 효과 유형을 공유한다.
